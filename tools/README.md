# Tools

Small scripts that are not part of the build.

| Script             | What it does                                                          |
|--------------------|-----------------------------------------------------------------------|
| `make-icons.py`    | Renders the desktop icons (`.png`, `.ico`, `.icns`) from the mark. No image library needed. |
| `build-lexicon.py` | Builds a full 135,000-word pronunciation dictionary from CMUdict.      |

Both are plain Python 3 with no dependencies.
